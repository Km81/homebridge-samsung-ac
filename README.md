# Homebridge Samsung AC (구형 모델 / Legacy Model)

구형 삼성 에어컨(TLSv1 통신 방식)을 Apple HomeKit에 연동하기 위한 Homebridge **액세서리** 플러그인입니다.

이 플러그인은 최신 Node.js(v17 이상) 환경에서 발생하는 TLS 호환성 문제를 해결하기 위한 패치를 포함하고 있습니다. 또한, **인증서가 플러그인에 내장**되어 있어 사용자는 더 이상 `.pem` 파일을 직접 구하거나 경로를 설정할 필요 없이, 오직 **IP 주소와 토큰만으로** 플러그인을 설정할 수 있습니다.

불안정한 에어컨 장치를 **자식 브릿지(Child Bridge)**에 격리하여 홈브릿지 전체의 안정성을 확보할 수 있습니다.

## 주요 기능 ✨

* **구형 삼성 에어컨 지원**: TLSv1 통신 프로토콜을 사용하는 모델 지원
* **최신 Homebridge 호환**: Node.js v17, v18, v22 등 최신 버전에서 발생하는 모든 TLS/HTTP 오류 해결
* **안정성 확보**: **자식 브릿지** 지원으로, 에어컨의 응답 없음 문제가 다른 액세서리에 영향을 주지 않도록 격리 가능
* **인증서 내장**: 별도의 `.pem` 파일 설정이 필요 없어 설정이 매우 간편함
* **UI 설정 지원**: Homebridge UI를 통해 모든 설정을 간편하게 구성 가능
* **안정적인 통신**: 상태 캐싱, 자동 재시도, 주기적인 상태 폴링 기능 포함

## 설정 ⚙️

이 플러그인은 **에어컨 한 대당 하나의 액세서리 설정**을 추가하는 방식으로 동작합니다. 홈브릿지 UI의 `config.json` 에디터를 사용하거나, 아래 예시를 참고하여 `accessories` 배열에 직접 추가할 수 있습니다.

| 키 | 설명 | 기본값 | 필수 |
| :--- | :--- | :--- | :--- |
| `accessory`| 등록할 액세서리 이름. **"SamsungAC"**로 고정 | - | **예** |
| `name` | 홈 앱에 표시될 에어컨의 이름 | - | **예** |
| `ip` | 에어컨의 고정 IP 주소 | - | **예** |
| `token`| 위에서 추출한 인증 토큰 | - | **예** |
... (나머지 설정 테이블은 이전과 동일) ...

#### `config.json` 직접 수정 예시

`accessories` 배열 안에, **에어컨 대수만큼** 아래와 같은 블록을 추가합니다.

```json
{
  "bridge": {
    "...": "..."
  },
  "accessories": [
    {
      "accessory": "SamsungAC",
      "name": "거실 에어컨",
      "ip": "192.168.1.50",
      "token": "TOKEN_FOR_LIVING_ROOM_AC",
      "pollingInterval": 30
    },
    {
      "accessory": "SamsungAC",
      "name": "침실 에어컨",
      "ip": "192.168.1.51",
      "token": "TOKEN_FOR_BEDROOM_AC",
      "pollingInterval": 30
    }
  ]
}

```

🚀 안정성을 위한 자식 브릿지(Child Bridge) 설정 (강력 추천)
에어컨의 응답 없음 문제가 다른 액세서리에 영향을 주지 않도록, 이 플러그인으로 등록된 에어컨들을 자식 브릿지로 옮기는 것을 강력히 권장합니다.

자식 브릿지 생성: 홈브릿지 UI의 '브릿지' 탭으로 이동하여, 오른쪽 상단의 '브릿지 추가' 버튼을 눌러 새 자식 브릿지를 생성합니다. (예: 에어컨 전용 브릿지)

액세서리 이동:

'브릿지' 탭에서 메인 홈브릿지의 설정(공구 아이콘)을 엽니다.

'브릿지된 액세서리' 탭으로 이동합니다.

목록에서 "거실 에어컨"과 "침실 에어컨"을 찾습니다.

각 액세서리의 '브릿지' 드롭다운 메뉴를 클릭하여, 방금 생성한 '에어컨 전용 브릿지'로 변경합니다.

저장 및 재시작: 설정을 **저장(Save)**하고, 홈브릿지를 재시작하면 완료됩니다.
